## The business need

The client needed home-inspector information collected from multiple directory websites and delivered in Excel. Different website structures required source-specific extraction workflows.

## My contribution

I developed separate Python scripts for each source website. I manually researched the page elements and XPath selectors, then automated the extraction, checked the records and prepared the spreadsheet deliveries.

## Collection and preparation

- Inspected each website and identified the required page elements.
- Built an extraction script around each source's structure.
- Checked the extracted records for missing and repeated values.
- Kept source batches separate and prepared readable, interactive Excel files.

Some source websites were inaccessible from my region. I worked with the sources available to me and adapted the scripts to their page structures.

## What I delivered

Separate Excel files for the website batches, with data checks and spreadsheet formatting for the client's use.

## Client outcome

The client accepted the delivery and hired me again.
